The canonical serialized version is `0.2-alpha.1`, replacing `0.1-alpha.2`. Documents
in the earlier version are migrated mechanically on input. This draft is paired with
implementation `0.2.0-alpha.1`; there is no dated release snapshot yet. On
publication, use the actual publication date for matching schema and normative-doc
directories, record the version mapping, and keep snapshots immutable.

Normative alpha rules appear in [architecture](/specification/draft/architecture),
[system profiles](/specification/draft/system-profile), [experience](/specification/draft/experience),
[patterns](/specification/draft/patterns), [recommendations](/specification/draft/recommendations),
[workflow interchange](/specification/draft/interchange) and the generated
[schema reference](/specification/draft/schema). The design is recorded in
[SEP-0000: local workbench](/seps/0000-local-workbench-and-multi-system),
[SEP-0000: workflow graph](/seps/0000-workflow-graph-and-openspec) and
[SEP-0000: local MCP and A2A discovery](/seps/0000-local-mcp-a2a-discovery),
plus the draft proposals for
[probing](/seps/0000-integration-probing-and-measured-facts),
[verification](/seps/0000-edge-verification-harness),
[review/adoption](/seps/0000-design-review-and-author-adoption),
[revision history](/seps/0000-openspec-revision-history-and-git-restore) and
[agent exposure](/seps/0000-agent-exposure-mcp-and-skill).
