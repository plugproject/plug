title: Introduction
---

Plug recommends architecture from a multi-system integration graph, operational
facts and the required UX of each connection. It evaluates a direct baseline, composes patterns
that close detected problems, and explains introduced components. The local
workbench can index the current project, inspect author-authorized read endpoints,
verify an edge, and preserve an explicit reviewed design in versioned OpenSpec.
Start with the
[quickstart](/docs/quickstart), [flight example](/docs/flight-search), or
[current specification](/specification/draft/index). This is an unreleased alpha;
there is no verified public URL or production SLO claim.
