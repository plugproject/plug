---
title: Concepts
---

A fact records declared, observed, synthetic or unknown evidence. Unknown is a null
value, never zero. Latency point estimates cannot prove end-to-end percentiles.
Result age is time since source snapshot (including delivery allowance). Change
frequency is a heuristic; it is not a correctness guarantee. Cache permission,
complete keys, and sharing scope must be explicit.

Hot-key popularity is a ceiling, while usable-hit coverage includes expiry and
refill gaps. Each candidate replays the supplied ordered trace with its exact policy.
Only counted post-warmup requests contribute to the stated traffic fraction.
A progress acknowledgement does not count as useful options.
