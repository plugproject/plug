# Security

The supported alpha is the current draft. Hosted analysis must never invoke
submitted URLs or fetch remote schemas. Demo execution uses private loopback
fixtures, opaque in-memory session tokens and bounded resources. Never submit
credentials or personal data. Descriptions and tokens are not logged or persisted.

A private vulnerability-reporting contact has not been configured in repository
facts. The owner must enable GitHub private vulnerability reporting or provide a
private route before launch. Do not post exploitable details or secrets in public
issues. Publicly report non-sensitive documentation problems only.
