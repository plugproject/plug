---
title: SEP guidelines
---

Use root Markdown proposals for major contract, behavior and process changes.
Start with 0000 and adopt the actual PR number once one exists. Actual maintainers
review through GitHub. Statuses are draft, in-review, accepted, final, rejected,
withdrawn, superseded and dormant. Final behavior requires implementation,
specification and regression tests. No approval history is invented.

See the [bootstrap proposal](/seps/0000-public-alpha-design).
